# Gmarket 웹 관리 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Gmarket 스타배송 검색 결과를 웹에서 일괄 등록·정리하고, SQLite DB에서 Playauto용 설정/최종 xlsx를 생성·다운로드하는 LXC 웹 앱을 만든다.

**Architecture:** Flask + Jinja/HTMX 웹 프로세스, 별도 Playwright crawl worker, SQLite WAL. 웹은 `crawl_jobs`를 만들고 worker가 검색 결과를 수집해 기존 `import_crawl`로 등록한다. export는 기존 `export_from_db`를 재사용하고 결과 파일은 임시 디렉터리에 둔다.

**Tech Stack:** Python 3.12, Flask 3.x, Jinja, HTMX(vendored), Playwright/Chromium, SQLite, openpyxl(vendored), gunicorn, Caddy, systemd.

**Spec:** `docs/superpowers/specs/2026-10-28-web-admin-design.md`

## Global Constraints

- Python 3.12. 새 웹 의존성은 Flask 3.x, gunicorn, Playwright만 추가한다. `openpyxl`은 기존 `vendor/`를 그대로 쓴다.
- 단일 관리자. 비밀번호는 `ADMIN_PASSWORD_HASH`, 세션 키는 `SECRET_KEY` 환경변수로만 받는다.
- DB는 `data/playauto.db`. 웹/worker 연결은 `PRAGMA journal_mode=WAL`, `PRAGMA busy_timeout=5000`을 적용한다. crawl worker는 1개만 실행한다.
- `market_price`는 Gmarket 검색 결과의 **쿠폰적용가**다.
- 상품 상세 페이지는 크롤링하지 않는다. Cloudflare/CAPTCHA 우회를 구현하지 않는다.
- 삭제는 hard delete다. `price_history`, `listings`, `products`를 한 트랜잭션에서 지운다.
- 기준 엑셀은 `data/reference/current.xlsx` 1개. export는 `data/exports/<id>/`에 만들고 24시간 뒤 정리한다.
- UI 문구는 한국어. 새 JS 프레임워크는 쓰지 않는다. HTMX는 `playauto/web/static/htmx.min.js`로 vendoring한다.
- 기존 CLI(`db-import`, `db-export`, 직접 변환)와 기존 55개 테스트를 깨지 않는다.
- 웹 의존성은 저장소 루트의 `.venv`에 설치한다. `.venv/`를 `.gitignore`에 추가한다.
- 이 Windows 작업공간의 테스트 명령:
  ```powershell
  $env:PYTHONPATH = "D:\Opencode\playauto_converter;D:\Opencode\playauto_converter\vendor"
  & "D:\Opencode\playauto_converter\.venv\Scripts\python.exe" -m unittest tests.test_web_db -v
  ```
- LXC의 테스트 명령:

- 각 task는 테스트 실패 확인 → 최소 구현 → 통과 확인 → commit 순서로 끝낸다.

## Review Focus

- Gmarket이 Cloudflare/봇 차단을 반환하거나 카드가 0개인 경우: job은 `failed`가 되고 사용자는 xlsx fallback 안내를 봐야 한다. (Task 6)
- 카드에 이름/가격/이미지/URL이 없거나 가격 형식이 깨진 경우: 해당 카드만 `skipped`되고 나머지는 등록되어야 한다. (Task 5)
- 같은 URL을 다시 등록한 경우: 중복 상품 없이 가격 이력만 추가되고 사용자가 수정한 마진/브랜드는 보존되어야 한다. (Task 4)
- 가격 이력과 listing이 있는 상품을 삭제한 경우: FK 오류 없이 함께 삭제되고 다른 상품은 남아야 한다. (Task 1)
- 헤더가 빠진 xlsx를 업로드한 경우: job이 명확한 오류로 실패하고 임시 업로드 파일이 남지 않아야 한다. (Task 4)

```python
from datetime import datetime, timezone
from pathlib import Path

from playauto.db import connect, ensure_schema


def new_conn(tmpdir):
    conn = connect(Path(tmpdir) / "test.db")
    ensure_schema(conn)
    return conn


def seed_product(
    conn,
    *,
    seq=1,
    name="테스트 상품",
    price=1000,
    brand="테스트브랜드",
    seller_code="MJ-0001",
    category_code="기타재화[35]",
    margin=0.15,
    order_url=None,
):
    now = datetime.now(timezone.utc).isoformat(timespec="seconds")
    order_url = order_url or f"https://item.gmarket.co.kr/Item?goodscode={seq}"
    product = conn.execute(
        "INSERT INTO products ("
        "source_seq, name, image_url, order_url, category_code, brand, "
        "created_at, updated_at, last_seen_at"
        ") VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?)",
        (
            seq,
            name,
            f"https://gdimg.gmarket.co.kr/{seq}/still/400",
            order_url,
            category_code,
            brand,
            now,
            now,
            now,
        ),
    )
    product_id = product.lastrowid
    listing = conn.execute(
        "INSERT INTO listings ("
        "product_id, seller_code, bundle_qty, sale_name, market_price, "
        "margin_rate, active, created_at, updated_at"
        ") VALUES (?, ?, 1, ?, ?, ?, 1, ?, ?)",
        (product_id, seller_code, name, price, margin, now, now),
    )
    listing_id = listing.lastrowid
    conn.execute(
        "INSERT INTO price_history ("
        "product_id, listing_id, price, observed_at"
        ") VALUES (?, ?, ?, ?)",
        (product_id, listing_id, price, now),
    )
    conn.commit()
    return product_id, listing_id
```

`delete_product`:

```python
def delete_product(conn: sqlite3.Connection, product_id: int) -> int:
    with conn:
        conn.execute(
            "DELETE FROM price_history WHERE product_id = ?", (product_id,)
        )
        conn.execute(
            "DELETE FROM listings WHERE product_id = ?", (product_id,)
        )
        cursor = conn.execute(
            "DELETE FROM products WHERE id = ?", (product_id,)
        )
        return cursor.rowcount
```

```python
import unittest
from pathlib import Path
from tempfile import TemporaryDirectory

from werkzeug.security import generate_password_hash

from playauto.web.app import create_app


class AuthTests(unittest.TestCase):
    def setUp(self):
        self.tmp = TemporaryDirectory()
        self.addCleanup(self.tmp.cleanup)
        self.app = create_app(
            {
                "TESTING": True,
                "SECRET_KEY": "test-secret",
                "ADMIN_PASSWORD_HASH": generate_password_hash("secret"),
                "DATABASE": str(Path(self.tmp.name) / "test.db"),
                "REFERENCE_PATH": str(Path(self.tmp.name) / "current.xlsx"),
                "EXPORT_ROOT": str(Path(self.tmp.name) / "exports"),
                "UPLOAD_ROOT": str(Path(self.tmp.name) / "uploads"),
                "BROWSER_PROFILE": str(Path(self.tmp.name) / "browser"),
                "EXPORT_TTL_HOURS": 24,
            }
        )
        self.client = self.app.test_client()

    def test_login_required_redirects(self):
        response = self.client.get("/")
        self.assertEqual(response.status_code, 302)
        self.assertIn("/login", response.headers["Location"])

    def test_login_success(self):
        self.client.get("/login")
        with self.client.session_transaction() as session:
            token = session["_csrf_token"]
        response = self.client.post(
            "/login",
            data={"password": "secret", "csrf_token": token},
        )
        self.assertEqual(response.status_code, 302)
        self.assertEqual(self.client.get("/").status_code, 200)

    def test_login_failure(self):
        self.client.get("/login")
        with self.client.session_transaction() as session:
            token = session["_csrf_token"]
        response = self.client.post(
            "/login",
            data={"password": "wrong", "csrf_token": token},
        )
        self.assertEqual(response.status_code, 200)
        self.assertIn("비밀번호", response.get_data(as_text=True))

    def test_post_without_csrf_rejected(self):
        response = self.client.post("/login", data={"password": "secret"})
        self.assertEqual(response.status_code, 400)

    def test_logout_clears_session(self):
        self.client.get("/login")
        with self.client.session_transaction() as session:
            token = session["_csrf_token"]
        self.client.post(
            "/login", data={"password": "secret", "csrf_token": token}
        )
        with self.client.session_transaction() as session:
            token = session["_csrf_token"]
        response = self.client.post(
            "/logout", data={"csrf_token": token}
        )
        self.assertEqual(response.status_code, 302)
        self.assertEqual(self.client.get("/").status_code, 302)

    def test_login_failure_rate_limit(self):
        for _ in range(5):
            self.client.get("/login")
            with self.client.session_transaction() as session:
                token = session["_csrf_token"]
            response = self.client.post(
                "/login",
                data={"password": "wrong", "csrf_token": token},
            )
            self.assertEqual(response.status_code, 200)
        self.client.get("/login")
        with self.client.session_transaction() as session:
            token = session["_csrf_token"]
        response = self.client.post(
            "/login", data={"password": "wrong", "csrf_token": token}
        )
        self.assertEqual(response.status_code, 429)
```

```python
from werkzeug.security import generate_password_hash

from playauto.web.app import create_app


def make_web_app(tmpdir, password="secret"):
    db_path = Path(tmpdir) / "test.db"
    app = create_app(
        {
            "TESTING": True,
            "SECRET_KEY": "test-secret",
            "ADMIN_PASSWORD_HASH": generate_password_hash(password),
            "DATABASE": str(db_path),
            "REFERENCE_PATH": str(Path(tmpdir) / "current.xlsx"),
            "EXPORT_ROOT": str(Path(tmpdir) / "exports"),
            "UPLOAD_ROOT": str(Path(tmpdir) / "uploads"),
            "BROWSER_PROFILE": str(Path(tmpdir) / "browser"),
            "EXPORT_TTL_HOURS": 24,
        }
    )
    return app, db_path


def login(client, password="secret"):
    client.get("/login")
    with client.session_transaction() as session:
        token = session["_csrf_token"]
    return client.post(
        "/login", data={"password": password, "csrf_token": token}
    )


def post_with_csrf(client, url, data):
    with client.session_transaction() as session:
        token = session["_csrf_token"]
    return client.post(url, data={**data, "csrf_token": token})
```

  - 유효 카드만 수집: `href`, `name`, `price`, `image` 모두 비어 있지 않아야 한다.
  - URL 기준 dedupe, 마지막 카드 값 사용, 첫 등장 순서 유지.
  - dedupe 후 `source_seq` 1..N.
  - name을 줄 단위로 나눈 뒤 정확히 `공식`, `상품`, brand와 같은 줄은 버리고, 남은 첫 줄이 brand로 시작하면 그 prefix를 제거한 뒤 공백 정리.
  - image가 `//`로 시작하면 `https:` prefix.
  - price는 기존 `parse_price`.
  - `CrawlData(rows=tuple(rows), skipped=skipped)`.
- `parse_capacity`: 정규식 `^(\d+(?:\.\d+)?)\s*(ml|g|개)$` (대소문자 무시). `kg`/`L`은 이번 단계에서 지원하지 않는다.
- `unit_price`:
  - `ml/g`: `market_price / (capacity * bundle_qty) * 100`, label `100ml`/`100g`
  - `개`: `market_price / (capacity * bundle_qty)`, label `개`
  - 반올림은 UI에서 처리하고 함수는 float 반환.
